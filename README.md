## 🌊 Marine Trace

Satellite Oil Spill Detection & Vessel Attribution

Marine Trace is an oil-spill investigation platform combining satellite imagery, environmental data, drift modelling, and AIS vessel tracking into one workflow.

## 🔎 Investigation Pipeline

Detect → Characterize → Environment → Drift → Origin → AIS → Attribute

🛰️ Detect — Sentinel-1 SAR oil-spill detection  
📐 Characterize — Spill area and geometry  
🌬️ Environment — ERA5 winds + CMEMS currents  
🌊 Drift — Forward spill simulation  
📍 Origin — Backward hindcast and origin estimation  
🚢 AIS — Historical vessel tracking  
📊 Attribute — Evidence-based vessel ranking  

## 🛠️ Tech Stack

React, JavaScript, Vite, Leaflet, OpenDrift/OpenOil, ERA5, CMEMS, AIS
